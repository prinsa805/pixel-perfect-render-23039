# High-tech command-deck redesign

## What will change
- Replace the soft glass styling with a precise cyber-terminal visual system: square panels, fine cyan rules, mono data typography, scanlines, grid details, and restrained status lighting.
- Rework the public landing screen into a credible Indian-market command interface while keeping sign-in and journaling actions prominent.
- Restyle the signed-in shell, navigation, dashboard metrics, charts, tables, forms, analytics, and settings consistently without changing data or calculations.
- Keep all views usable on compact screens by collapsing terminal rails and preserving horizontal access to dense market data.

## Technical details
- Centralize the new semantic colors, shadows, panel treatments, and motion in the global design tokens.
- Reuse existing routes and trading logic; this is presentation-only work.
- Use existing shared controls and icons, with accessible labels and reduced-motion behavior.
- Verify the result at desktop and mobile sizes, then check preview errors and key navigation flows.
